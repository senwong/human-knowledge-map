# Roadmap

## v1.0 — Interactive knowledge map

- Next.js + TypeScript application
- zoom / pan / minimap
- clickable knowledge nodes
- node details
- typed graph relationships
- search and knowledge-depth filtering
- demo learning path from natural numbers to Transformer
- Docker startup

## v1.1 — Knowledge path engine

- choose start and destination concepts
- shortest/teachable path calculation
- highlight prerequisites and missing concepts
- path summary such as “137 concepts remaining”
- richer cross-domain relationships

## v1.2 — Personal knowledge overlay

- learner profile
- mastered / learning / weak / review / unlearned states
- progress visualization over the global graph
- recommended next node
- spaced-review metadata hooks

## v1.3 — Multi-scale knowledge map

- semantic zoom instead of only filtering
- cluster nodes into subjects at low zoom
- progressively expand concepts at high zoom
- focus mode and neighborhood exploration
- breadcrumb / navigation history

## v1.4 — AI-assisted graph authoring

- DeepSeek/OpenAI-compatible provider interface
- propose nodes and relationships
- provenance and confidence
- review queue before publishing generated knowledge

## v2.0 — AI Teacher integration

- curriculum graph service
- student learning path planning
- assessment result → mastery update
- forgetting model → review recommendations
- connect to the AI Teacher classroom workflow
